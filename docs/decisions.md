# Decisions

One entry per decision: **date — what** — why.

- **2026-10-09 — PreCompact reuses handoff-check.sh with `--force`** — one checkpoint implementation; `--force` skips the ccusage/time thresholds because compaction is itself the trigger.
- **2026-10-09 — Stop hook reads the test command from a `Test command:` line in CLAUDE.md** — no config file to maintain; absent line means skip silently. `stop_hook_active` prevents block loops.
- **2026-10-09 — Hook logic lives in .claude/hooks/*.sh, not inline in settings.json** — avoids JSON/shell quoting differences between macOS and Windows Git Bash.
- **2026-10-09 — One Stop script (`stop.sh`) runs tests, then the checkpoint** — hooks on the same event run in parallel, so separate entries could commit mid-test or checkpoint a failing tree.
- **2026-10-09 — `--force` records the checkpoint baseline** — otherwise the next PreToolUse re-fired and made a duplicate commit.
- **2026-10-09 — Test command capped at 240s inside a 360s Stop hook** — a hung suite must fail visibly, not get the whole hook killed; the remaining time is reserved for the checkpoint. Pure-bash watchdog because macOS has no `timeout`.
- **2026-10-09 — Checkpoint runs `git pull --rebase --autostash` before pushing; on conflict it aborts and leaves the commits local** — a bot or another machine pushing otherwise made every checkpoint push fail silently. The conflict is written to the gitignored `.claude/.last_checkpoint_sync_problem` and shown by `session-start.sh`; nothing is ever forced.
- **2026-10-09 — Review rule applies to finished features and milestones, not checkpoint pushes** — checkpoints are backups; reviewing each one would stall the session for no benefit.
- **2026-10-09 — The checkpoint note covers every sync failure, not only rebase conflicts** — a failed pull (offline, autostash-pop conflict), a rejected push and a repo left mid-rebase all leave the commits local and are written to `.claude/.last_checkpoint_sync_problem`; a clean checkpoint removes the note. Tested against a local bare remote (conflict, unreachable remote, pre-receive rejection, mid-rebase).
- **2026-10-09 — Checkpoints never commit a file over 50 MB, and commit nothing if one checkpoint would add over 200 MB** — a blanket `git add -A` once swept ~1.2 GB of unwanted files (mostly 30 MB PDFs) into a repo's history. Single files over `CHECKPOINT_MAX_FILE_BYTES` (default 50 MB) that are untracked, modified or already staged are left out of the commit (unstaged if needed), stay on disk, and are listed in `.claude/.last_checkpoint_sync_problem`. If the remaining pending changes total more than `CHECKPOINT_MAX_TOTAL_BYTES` (default 200 MB), the working tree is not committed at all, because the per-file limit alone does not stop a folder of many mid-size files. Symlinks count as links, not their target. Tested: 60 MB untracked, 55 MB modified, staged big file, symlinks, 4 x 30 MB folder over a 100 MB test cap, plus bash 3.2.
- **2026-10-17 — Checkpoint pull uses `git pull --rebase=merges --autostash`** — plain `--rebase` flattened local merge commits into single commits when GitHub had newer work. `--rebase=merges` keeps merges as merges; a conflicting pull is still aborted, the commits stay local and nothing is forced. Limit: a merge with hand edits beyond conflict resolution would lose those edits if the redo does not conflict. Fix verified in the cookbook repo (`docs/handoff-template-hook-fix.md`).
- **2026-11-10 — Freight lookup is a static site in `site/` with no build step** — Sonny only needs a page; plain HTML/JS keeps GitHub Pages hosting free and simple.
- **2026-11-10 — `build_data.py` writes compact JSON; the browser does the lookups** — ZIP only mode then needs no network calls, and new UPS files only need a rerun.
- **2026-11-10 — Hawaii and Alaska zones come from the chart's footnotes by full 5-digit ZIP** — the 088 chart has no 967/968/995-999 rows. Footnotes give only Ground, Next Day Air and 2nd Day Air, so the other services show "Not available".
- **2026-11-10 — Zone file is read as `.xlsx` with openpyxl** — UPS sent `ups Zone.xlsx`; one library covers both files. An old `.xls` must be resaved as `.xlsx`.
- **2026-11-10 — Autocomplete tries Smarty v2 first, falls back to US Autocomplete Pro for the visit** — v2 is the newer endpoint; the fallback keeps the page working if v2 rejects the key. Errors 402 and 429 do not trigger the fallback since Pro would fail the same way.
- **2026-11-10 — Embedded Smarty key lives in `site/config.js` and is committed** — embedded keys are public by design and locked to the allowed hosts.
- **2026-11-10 — Recent lookups store the result, and clicking one recomputes zone and rural status locally** — no extra Smarty lookups, and the data stays current after a UPS update.
